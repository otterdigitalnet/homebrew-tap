# Otter Beam Homebrew tap

```sh
brew install --cask otterdigitalnet/tap/otterbeam
```

Installs the notarized Otter Beam host for macOS from https://beam.otterd.com. The cask is updated by `scripts/update_homebrew_cask.sh` in the main repo on every macOS release; the app then keeps itself current via Sparkle.
